## Overview
This was the first big project I worked on, while I was in college, as part of a paid co-op. New Century Energy Game (NCEG) was an educational game for the HISD school system. In the game you built power stations to supply different cities with different needs. Students would get scores based on power generated, pollution made, and happiness of the population.

## Technology
The main application was built in Unity3D but an updater was made in .Net. My main contributions were converting the whole program to use threads/co-routines, optimizing power lines with the A* algorithm, and creating the delta updater based on [Sparkle](https://github.com/sparkle-project/Sparkle).

## Fun facts
One power station was built up to near completion, for hydro power, but never finalized. There was a continuation of the game called New Digital Energy (NDE) Game.

## Lessons Learned
Working with a school system and generally across many different machines/environments brought up some initial troubles. Some had IT distribute the application across machines and for some schools it was the teachers. I had navigate the different permissions and make sure all machines were able to have the latest version.
