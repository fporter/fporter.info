## Overview
This visual novel + educational game that was focused on teaching coding and robotics. I forget the main story line but there was a long of graphic novel pages, dialog, and the puzzles were using code blocks to control a robot for various objectives.

## Technology
This was mainly Unity3D with a webpage for teachers to manage classes and see their progress/reports. I mainly helped with the graphic novel viewer, navigation for the walking portions, UI implementation.

## Fun fact
This project was the first time I was able to be a scrum master, where I was able to help the team plan sprints and directed the sprint reviews. While I continued to scrum master for a few more projects, this one had the largest team.
